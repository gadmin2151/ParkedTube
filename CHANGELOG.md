- Licensed ParkedTube under PolyForm Noncommercial 1.0.0.

## 1.4.0 - 2026-08-14

- Consolidated the project into one ParkedTube application module.
- Added reproducible Docker debug and signed release builds.
- Added Android lint, URL-policy unit tests, APK signature checks, and checksums.
- Restricted WebView navigation to HTTPS YouTube and Google sign-in pages.

- Added GitHub Actions for CI, artifact attestation, Packages, and Releases.

- Added a landscape Android Auto experience and a Russian/English on-screen keyboard.
- Kept phone orientation adaptive and the phone system keyboard enabled.
